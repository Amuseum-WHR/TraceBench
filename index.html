TRACE-Bench teaser

Multi-reference image generation combines several references into one output, but benchmarks often collapse this combinatorial space into coarse task bins. TRACE-Bench instead decomposes prompts into explicit capability operators so that success and failure can be traced to concrete skills—such as anchoring a subject, disentangling attributes, applying edits, or composing scenes—rather than a single holistic score.

Abstract

Recent advances in unified multimodal models have significantly improved multi-reference image generation, yet existing benchmarks still organize evaluation around predefined task types, such as "subject composition."

This task-oriented design is ill-suited for the combinatorial nature of multi-reference generation, resulting in fragmented coverage, uncontrolled complexity, and holistic scores that offer no diagnostic value. We rethink multi-reference evaluation from a capability-oriented perspective.

We observe that diverse multi-reference tasks share a common set of atomic operations, which we formalize as four capability operators: Anchor (f), Disentangle (g), Apply (⊕), and Compose (C). Any multi-reference prompt can then be represented as a compositional formula over these operators, with complexity naturally quantified by the number of operator slots.

Building on this formulation, we construct TRACE-Bench, comprising approximately 1,600 evaluation cases across slot counts 1-8, built from 631 formula templates and around 4,000 reference images spanning diverse artistic styles and real-world subjects.

The symbolic structure of each case directly drives an operator-aligned evaluation protocol for per-capability scoring and a diagnostic tree analysis for recursive failure localization. Evaluating 9 leading models reveals insights invisible to holistic scoring: the primary bottleneck lies in disentanglement (g) and attribute binding (⊕) rather than scene-level composition (C), with even the best model scoring only 0.74 on attribute fidelity.

Benchmark overview

TRACE-Bench connects symbolic structure (how a prompt uses each operator) to measurable behavior (per-operator scores and diagnostics). The following figures walk through the formulation, dataset construction, and aggregate model comparison.

Capability operators and formulas

We argue that diverse multi-reference prompts can be written as short formulas over four operators: Anchor (f) grounds identity from a reference, Disentangle (g) separates factors such as pose or style, Apply (⊕) binds attributes to parts, and Compose (C) builds the final layout. Slot count reflects formula complexity and aligns with how we stratify evaluation.

Figure. Operator definitions and how natural multi-reference prompts map to compositional formulas (see paper for formal notation and examples).

Data construction and evaluation pipeline

The benchmark is built from curated references, template-driven formula instantiation, and automated rendering of evaluation pairs. Each case carries explicit operator annotations so that scoring and error analysis stay aligned with the intended capability, rather than conflating unrelated errors into one score.
